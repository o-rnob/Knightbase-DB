Read the data before the returns. This runs on real KnightBase-DB prices, not synthetic data — with real problems.
→ 0.54% of all price rows are unadjusted for splits/dividends (only 8 of ~870 tickers are adjusted). Backtest returns below are price-return only, not true total return.
→ There is a real, undocumented blackout in DSE price coverage from Jan 2021 to Aug 2024 — the archive ends Dec 2020, gap-fill data only starts again in 2025. No ticker used here has data in that window; the charts show the gap as-is rather than interpolating across it.
→ New finding: the DSEX/DS30 index tables' `close` column is 100% NULL (3,095 / 3,097 rows) — not previously logged. This dashboard uses the daily `high` value as a proxy for the index level, which is not identical to a true close.
